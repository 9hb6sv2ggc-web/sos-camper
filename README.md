# Rumbo España

Guía web instalable para caravanistas en España: 3.450 lugares de pernocta de OpenStreetMap y 15 restaurantes recomendados, con búsqueda, filtros, fichas, mapa y enlaces para abrir cada lugar.

## Publicar en GitHub Pages

El sitio está preparado para publicarse desde la raíz de la rama `main`. En GitHub, abre **Settings → Pages**, selecciona **Deploy from a branch**, elige `main` y la carpeta `/ (root)`, y guarda. Cuando aparezca la dirección publicada, ábrela en el teléfono.

- iPhone: Safari → Compartir → Añadir a pantalla de inicio.
- Android: Chrome → botón **Instalar app** o menú ⋮ → Instalar aplicación.

El catálogo está integrado. El mapa necesita internet. Datos de OpenStreetMap consultados el 9 de octubre de 2026; confirma precios, apertura, servicios y normas antes de viajar.
